Instalar agente

Instale o agente de inventário e saúde numa máquina da rede para que ela apareça no console. Escolha o sistema operacional e siga os passos abaixo.

Requisitos: abra o PowerShell como Administrador na máquina alvo. O Python 3 deve estar instalado — o instalador tentará instalá-lo automaticamente via winget caso não encontre.
  • 1
    Execute o instalador automatizado
    No PowerShell (Administrador) da máquina alvo, cole e execute o comando abaixo. Ele baixa o agente, instala as dependências e agenda a coleta automática.
    PowerShell · Admin
    irm [SERVER_URL]/api/agent/installer.ps1 | iex
  • 2
    Instalação manual (alternativa)
    Se preferir não usar o instalador automatizado, baixe o script do agente e o arquivo de configuração já preenchido com a chave de API deste servidor. Coloque os dois na mesma pasta e execute python agent.py.

    Arquivos do agente

    agent.py + config.json pré-configurado para este servidor.

    agent.py config.json
Requisitos: o comando abaixo cria a pasta /opt/itam-agent, instala as dependências Python e registra a coleta horária via cron. É necessário ter privilégios sudo.
  • 1
    Execute o instalador automatizado
    Abra o terminal da máquina alvo e execute o comando abaixo:
    Bash
    curl -sSL [SERVER_URL]/api/agent/installer.sh | bash
  • 2
    Instalação manual (alternativa)
    Baixe os arquivos do agente e configure o cron job ou daemon manualmente:

    Arquivos do agente

    agent.py + config.json pré-configurado para este servidor.

    agent.py config.json
Após a instalação, a máquina envia o primeiro inventário em até 1 minuto e aparece automaticamente no console de ativos.
