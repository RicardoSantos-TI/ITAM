Como cadastrar novos computadores

Siga as instruções abaixo para instalar o agente de inventário e saúde em outra máquina e conectá-la a este painel.

Requisitos do Windows: Você precisa abrir o PowerShell como Administrador na máquina alvo para rodar o comando de instalação. Certifique-se de que o Python 3 está instalado (o script tentará instalar automaticamente via winget caso não encontre).
  • 1
    Copie e execute o instalador automatizado
    Abra o PowerShell (Administrador) na máquina alvo e execute o seguinte comando de linha única:
    POWERSHELL (ADMIN)
    irm [SERVER_URL]/api/agent/installer.ps1 | iex
  • 2
    Instalação Manual (Alternativa)
    Se preferir não usar o instalador automatizado, você pode baixar o script do agente e o arquivo de configuração pré-configurado com a API Key deste servidor e colocá-los na mesma pasta.

    Arquivos do Agente ITAM

    Baixe ambos os arquivos e execute python agent.py na máquina de destino.

    Baixar agent.py Baixar config.json
Requisitos: O comando abaixo baixa o instalador do Linux, cria uma pasta em /opt/itam-agent, instala as dependências Python necessárias e registra a execução horária via cron. É necessário possuir privilégios sudo.
  • 1
    Copie e execute o instalador automatizado
    Abra o terminal da máquina alvo e execute o comando abaixo:
    SHELL BASH
    curl -sSL [SERVER_URL]/api/agent/installer.sh | bash
  • 2
    Instalação Manual (Alternativa)
    Assim como no Windows, você também pode obter os arquivos brutos do agente e do config para estruturar manualmente o seu script:

    Arquivos do Agente ITAM

    Baixe os arquivos e configure o cron job ou daemon manualmente.

    Baixar agent.py Baixar config.json
